# Quantifying Rocket NOx Emissions Using Geostationary Satellite Observations

Code and data accompanying the GRL manuscript by Palmo et al.

This repository uses **TEMPO Level-2** tropospheric NO₂ columns with Gaussian-smoothed plume detection and an SNR threshold of **4.09** to estimate launch NOₓ emissions via the integrated mass enhancement (IME) method.

## Repository structure

```
paper_submission_GRL/
├── setup.py                 # Package metadata and dependencies
├── tempo.py                 # TEMPO data loading utilities
├── launches.py              # Launch catalog (GCAT) helpers
├── utils.py                 # Shared helpers
├── tol_colors.py            # Color maps for figures
├── detect_plumes.py         # Plume detection algorithm
├── emissions.py             # IME calculation and L2 processing
├── compute_emissions.py     # Batch plume detection + emissions per launch
├── compute_emissions.sh     # SLURM wrapper for compute_emissions.py

├── download_tempo.py        # Download TEMPO L2 files from NASA Earthdata
├── make_animation.py        # Optional animation utilities
├── figure_1.ipynb           # Fig. 1 + Movie S1 (Artemis II case study)
├── figure_2.ipynb           # Fig. 2 (example Falcon 9 plume)
├── figure_3.ipynb           # Fig. 3 (IME vs launch mass)
├── figure_4.ipynb           # Fig. 4 (Falcon 9 vs bottom-up estimates)
├── figure_S1.ipynb          # Fig. S1 (detection rate vs mass)
├── figure_S2.ipynb          # Fig. S2 (uncertainty propagation)

```

## Reproduction workflow

Run from this directory (`paper_submission_GRL/`). TEMPO L2 files are read from `TEMPO_DATA_PATH` in `analysis.py` / `emissions.py` (default: `/home/jpalmo/fs09/Datasets/TEMPO`); change that path if needed.

### 1. Plume detection and per-launch emissions

```bash
# Interactive
python compute_emissions.py

# Or on SLURM (edit compute_emissions.sh for your environment)
sbatch compute_emissions.sh
```

`plumes/` already contains this paper's detection run. Re-running the step above overwrites:
- `detections.csv`
- `*.nc` plume subsets per launch
- `figs/detections/` and `figs/nondetections/` QC plots

### 2. Merge detections and build analysis tables

```bash
python analysis.py
```

Writes `data/detections_final.csv` and `data/initial_detections.csv` (includes Artemis II from `artemis_launch/artemis_emissions_merged.csv`).

### 3. Uncertainty propagation (Fig. S2 + central estimates)

Run `figure_S2.ipynb`. It writes:
- `data/central_ime_estimates.csv` (used by Figs. 3, 4, and S1)
- `figures/fig_S2_scenarios.png`, `figures/fig_S2_sensitivity.png`

### 4. Manuscript figures

| Notebook      | Manuscript figure | Main outputs |
|---------------|-------------------|--------------|
| `figure_1.ipynb` | Fig. 1, Movie S1 | `artemis_launch/plume_evolution.png`, `artemis_launch/artemis_time_series.png`, `artemis_launch/output.mp4` |
| `figure_2.ipynb` | Fig. 2 | `figures/fig_2a.png`, `fig_2b.png`, `fig_2c.png`. Reads `data/initial_detections.csv`, a local TEMPO L3 file, and `MAPBOX_TOKEN` |
| `figure_3.ipynb` | Fig. 3 | `figures/fig_3.png` (run scatter/power-law cells; earlier bar-chart cells are optional) |
| `figure_4.ipynb` | Fig. 4 | `figures/fig_4.png` |
| `figure_S1.ipynb` | Fig. S1 | `figures/fig_S1.png` |
| `scd.ipynb` | Figs. S3 and S4 | `figures/fig_S3.png`, `figures/fig_S4.png` |

Bundled `data/*.csv` files are snapshots from the final analysis; **re-run steps 1–3** before regenerating figures for a fresh submission archive.

## External data

- **TEMPO L2 NO₂**: [NASA ASDC](https://asdc.larc.nasa.gov/project/TEMPO) (V03/V04 under `TEMPO_DATA_PATH`)
- **Launch catalog**: [GCAT](https://planet4589.org/space/gcat/)
- **GEOS-CF**: NASA GMAO (for NOₓ:NO₂ ratios in `emissions.py`)
